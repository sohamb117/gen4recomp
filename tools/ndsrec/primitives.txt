# The symbols the ROM-only build must find in a ROM: the host layer
# (games/platinum/pc/{src,hw,wasm/src}, tools/armrec/armrec_rt.c and
# games/diamond/pc/src, as games/diamond/pc/mk/host.mk compiles them)
# either replaces them with C or refers to them by name.
#
#   override  a guest function the host defines: armrec drops the body and
#             every call and dispatch goes to the host (--host-override)
#   ref       a guest function or object the host calls or reads by name
#
# Derived from Diamond's build: `override` is every name the host objects
# define that the ROM link map (arm9.elf.xMAP) has as code, plus
# games/diamond/pc/host_overrides.txt; `ref` is every name the host
# objects leave undefined that the link map has (libc excluded), plus the
# asm names the bridge turns into addresses inside host C (pc_agb_slot.c,
# pc_dp_agb.c, pc_tp.c, pc_wm.c, pc_dp_snd.c). tools/ndsrec/sigs.py learns
# a signature for each from Diamond and finds it in another ROM.
#
