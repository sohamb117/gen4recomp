# Boots a save, casts the registered Old Rod at the water in front of the

# The first lines are lab-continue.txt's, unchanged. Y uses the registered
# item, which is how a player fishes: a rod is a key item on the Y button.
#
# The a press at frame 5750 is the whole script. fishingTask_SetFishWait
# draws the wait before the bite from the RNG and FishingTask_ReeledInEarly
# answers an A press that arrives before it, so mashing A cannot catch
# anything here. The window this run has to hit opens at frame 5707 and is
# 90 frames wide, measured with PC_TRACE_FISH over this exact script,
# because the run is deterministic and the frame is therefore a constant. It
# is not a number to nudge: change anything before it and it has to be
# measured again.
#
# The Old Rod's encounter rate is 25%, and this save's first three casts
# came back empty, which is why its bite is 2000 frames later than the
# other two rods'. The B presses are what closes "not even a nibble"
# between them; B rather than A, because an A press during a cast is
# the early reel-in.
#
# Everything after the catch is lab-battle.txt's A in bursts, which fights out
# the wild encounter the catch starts and clears the messages either side of
# it.
