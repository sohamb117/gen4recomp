# Drives one Super Contest from the frame the contest lab starts it.
#
# Three things have to be pressed and only one of them is obvious. The
# dress-up round and the dance round both run on a timer and end on their own
# with nothing touched. The acting round does not: it asks for a move, and
# then, on a second screen the move menu gives no hint of; it asks which
# of the three judges should rate it. A run that only presses A answers the
# first question and then picks whatever the cursor is sitting on in the
# second, which is the EXIT button, and lands back on the move menu forever.
#
# And the move menu cannot be answered the same way twice. A move that has
# been performed goes grey and is refused; the cursor has to be walked to a
# fresh one each performance. So the cycle below is a direction key followed
# by two A presses; the move, then the judge, with the direction walking
# the 2x2 move grid right, down, left, up. A direction that lands on the judge
# screen instead is harmless: every square there but one is a judge, and the
# one that is not just returns to the move menu, which the next cycle answers.
#
# The presses before frame 5000 are the ordinary CONTINUE opening.
# The presses stop at 44700: the contest is over by then, and a run
# that keeps mashing A on the Hearthome pavement starts conversations
# instead, which never lets the field settle for the end-of-run save.
