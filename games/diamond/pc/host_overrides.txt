# assembly: arm9/asm/*.s, or mwcc `asm` bodies inside NitroSDK C files.
#
# Consumed by pc/mk/armrec.mk (armrec --host-override: the name is not
# emitted, every recompiled call to it is a boundary call to the host
# definition, and its guest address dispatches there) and by pc/mk/game.mk
# (the asm-in-C body is not extracted). Written by the host slice
# (pc/mk/host.mk) from the definitions its objects export; every name below
# was checked against arm9/build/<ver>.us/arm9.elf.xMAP (address, object)
# and its D source. SDK functions D has in plain C need no entry: game.mk
# compiles D's SDK weak, and the host's strong definition wins.
#
# One name per line, `#` comments.
