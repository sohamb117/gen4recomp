morisoba//pokeweb

Native game cores: pret's pokeplatinum, pokediamond, pokeheartgold, pokeruby,
and pokeemerald decompilations, plus nativeplat's port and ROM recompilation
layers. See the accompanying GPL-3.0 license and repository sources:
https://github.com/sohamb117/gen4recomp/tree/web-ready
Core provenance is recorded in cores/manifest.json. The separate Gen1Recomp
engine retains its source archive and notices under engines/gen123/.
Pokemon is a trademark of Nintendo / Creatures Inc. / GAME FREAK inc.
The portable release excludes cartridge images and save files. The hosted
deployment distributes its separately allowlisted encrypted cartridge packages.

React and React DOM: Meta Platforms, Inc. and affiliates, MIT.
Lucide icons: Lucide contributors, ISC.
IBM Plex Mono: IBM, SIL Open Font License 1.1.
Space Grotesk: Florian Karsten, SIL Open Font License 1.1.
Fonts are currently requested from Google Fonts; system monospace/sans-serif
fallbacks work if the font service is unavailable.

Build tools (not required by players): Vite (MIT), TypeScript (Apache-2.0),
Binaryen (Apache-2.0), WABT (Apache-2.0), wasi-sdk and wasi-libc.
Exact JavaScript package versions are recorded in package-lock.json.
